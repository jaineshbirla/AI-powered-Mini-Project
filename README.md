# AI-Powered Text Summarizer & Sentiment Analyzer 🚀

An interactive web application built with Python, Streamlit, and Hugging Face transformers that performs automated text summarization and sentiment analysis.

## Features
- **Sentiment Analysis:** Detects whether text carries a positive or negative tone with confidence scores.
- **Text Summarization:** Condenses long articles or paragraphs into concise summaries using transformer models (`distilbart`).
- **Interactive UI:** Clean web interface built using Streamlit.
